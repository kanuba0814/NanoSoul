# 无 PCB · 三电机接线图（电源/地母排版）

> **为什么有这一版**：实测踩过一次坑——电机一转，带 M0/M1 的那片桥 VM-GND 从 6.1V 塌到 1.3V。
> 查实是**电机回流地没有干线**：只"连到公共地"，但回流被逼着走细线/串接，安培级电流在细线上压降 ~5V → 桥 GND 被顶起 → VM-GND 只剩 1V 多。
> **解法**：用面包板一整排做**又宽又短的地干线（母排）**，所有地汇到它、再粗线回 XL6009 OUT−。本图把这套固化下来，防复现。

## 0. 一句话原则（红线）
**电机的大电流走「母排干线」，不走细线串接；所有地汇到同一条「星地母排」。**

## 1. 拓扑总览（两条母排）

```
电池1S ─B+/B−→ TP4056(保护+充电) ─OUT+→ 开关 ─→ XL6009(升5.9V)
                                                   │OUT+              │OUT−(粗!)
                                                   ▼                  │
                                            INA219(串入测总流)         │
                                                   │Vin−              │
      ＋5.9V 红轨(功率正)                          ▼                  ▼
  ●━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━●            (接红轨)         GND 蓝轨 ★星地
     │VM            │VM                                       ○━━━━━━━━━━━━━━━━━●
  [TB6612#1]     [TB6612#2]                                     ▲   ▲   ▲   ▲
   M0(A)/M1(B)    M2(A)                                         │   │   │   │
     │GND──────────┘GND   ── 粗回流，就近落蓝轨 ───────────────┘   │   │   │
                                                                   │   │   │
  开发板GND ───────────────────────────────────────────────────────┘   │   │
  编码器GND(蓝)×3 ─────────────────────────────────────────────────────┘   │
  XL6009 OUT− (星地锚点) ───────────────────────────────────────────────────┘

  电脑USB → 开发板(P4)：  3V3 → 两片桥VCC + 编码器VCC(黑)
                         GPIO → PWM/IN1/IN2/STBY + 编码器A/B
```

- **红轨** = +5.9V 电机功率正（XL6009 OUT+ 经 INA219 串入）。
- **蓝轨** = GND ★星地（XL6009 OUT− 为锚点；两片桥 GND、开发板 GND、编码器 GND 全汇这）。
- 开发板由**电脑 USB**单独供电，只往外出 3V3 逻辑 + GPIO；**不**给电机出力。

## 2. 电源链（电池侧）

| 段 | 接法 |
|---|---|
| 电池 1S LiPo | → TP4056 `B+`/`B−`（充电 + DW01 保护） |
| TP4056 `OUT+` | → **开关** → XL6009 `IN+` |
| TP4056 `OUT−` | → XL6009 `IN−` |
| XL6009 | 输出电位器调到 **5.9V**（空载量准） |
| XL6009 `OUT+` | → INA219 `Vin+` |
| INA219 `Vin−` | → **＋5.9V 红轨** |
| XL6009 `OUT−` | → **GND 蓝轨（星地锚点）**，用粗线 |
| INA219 `VCC/GND/SDA/SCL` | → 开发板 `3V3 / 蓝轨 / IO20 / IO21`（测**全部电机总电流**） |

## 3. 两片 TB6612 桥

> VM=功率(红轨) / VCC=逻辑(3V3) **别接反**；GND 落蓝轨**要粗**；多个 GND 焊盘内部同网，接一个即可（接两个更稳）。

**桥 #1 —— 驱 M0(A路) + M1(B路)，STBY=IO51**

| 桥脚 | 接到 | | 桥脚 | 接到 |
|---|---|---|---|---|
| `VM` | 红轨 +5.9V | | `STBY` | 开发板 **IO51**（高=使能/低=急停） |
| `VCC` | 开发板 3V3 | | `PWMA/AIN1/AIN2` | IO2 / IO3 / IO4 → **M0** |
| `GND` | 蓝轨 星地（粗!） | | `AO1/AO2` | M0 电机 红/白 |
| | | | `PWMB/BIN1/BIN2` | IO5 / IO24 / IO25 → **M1** |
| | | | `BO1/BO2` | M1 电机 红/白 |

**桥 #2 —— 驱 M2(A路)，STBY=IO52**

| 桥脚 | 接到 | | 桥脚 | 接到 |
|---|---|---|---|---|
| `VM` | 红轨 +5.9V | | `STBY` | 开发板 **IO52** |
| `VCC` | 开发板 3V3 | | `PWMA/AIN1/AIN2` | IO26 / IO27 / IO32 → **M2** |
| `GND` | 蓝轨 星地（粗!） | | `AO1/AO2` | M2 电机 红/白 |
| | | | B路(`PWMB/BIN*/BO*`) | 空，备用 |

> 两片 STBY 分开接（杜邦不够没并）：固件 `motors_enable()` 同时拉 IO51+IO52。以后有线想并到一个脚也行，改固件即可。

## 4. 电机（HH-N20-3 丝印）

| 线色 | 含义 | 接到 |
|---|---|---|
| 红 | 电机电源+ | TB6612 `AO1`(或 `BO1`) |
| 白 | 电机电源− | TB6612 `AO2`(或 `BO2`) |

| 线色 | 含义 | 接到 | M0 | M1 | M2 |
|---|---|---|---|---|---|
| 黑 | 编码器 VCC | 开发板 **3V3**（**不**接电机电源！datasheet 硬性） | — | — | — |
| 蓝 | 编码器 GND | 蓝轨 星地 | — | — | — |

## 6. 防复现 · 接线红线（重点）

1. **回流走干线**：每片桥 `GND` 用**短粗线/多根并联**就近落到**蓝轨**；蓝轨再**粗线**回 `XL6009 OUT−`。**绝不**让电机电流经信号地/细杜邦绕回。
2. **单点星地**：`XL6009 OUT−`＋两片桥 GND＋开发板 GND＋编码器 GND，全汇到**蓝轨这一条**。共地是硬需求。
3. **VM 同理**：红轨从 `XL6009 OUT+`(经 INA219)来，每片桥 `VM` 短线就近接红轨；**别从另一片桥串接**。
4. **量验（带载，电机转着量）**：`桥GND ↔ XL6009 OUT− ≈ 0V`、`桥 VM-GND ≥ 5.5V`。出现几伏 = 那段干线不行（这次就是 GND 段出 5V）。
5. **面包板母排电流**：单排约 1–2A；三电机同堵 ~1.2A 偏临界。高电流段尽量短、端子插紧；红/蓝各占**一整排**，不够就**上下两排并联**加宽。
6. **编码器地的精细处理**：编码器 GND 也上蓝轨，但尽量从**靠开发板GND/OUT−那一端（安静端）**入轨，别紧挨大电流桥 GND 入点——减少电机电流在轨上的抖动串进编码器参考（否则计数会带噪）。
7. **旁路电容**：每片桥 `VM↔GND` 就近补 **100µF + 0.1µF**，吸 PWM 开关尖峰，进一步稳 VM。

## 7. 上电自检顺序（防烧件）

1. 先不插电机，只接电源链 → 量红轨 ≈5.9V、蓝轨对 OUT− ≈0V。
2. 插一片桥（VM/GND/VCC/STBY），STBY 先低 → 量 VM-GND ≈5.9V 不塌。
3. 接电机、固件逐个轮转 → 带载量 `桥GND↔OUT−≈0`、`VM-GND≥5.5V`、编码器三路各自只在被驱动时跳。
4. 任一步 VM 塌 / GND 出压差 → 立刻断电，回第 6 节查那段干线。
