# 02 硬件规格（载板 + 整机 BOM）

> 本文是 NanoSoul 当前项目的**硬件规格主文档**，与 [`02_硬件规格_附录_驱动可用性.md`](02_硬件规格_附录_驱动可用性.md) 配套（附录管「外设有无官方驱动」，本文管「选型 + 连接 + BOM」）。
> 基线 = 当前 docs(01–04) + 补全；**本版去掉悬崖传感器**（IMU 兜底 lift/碰撞）；**不上** ToF / Qi 无线充 / MochiPet costume（详见 §9）。
> 引脚分配见 [`BOARD_MAPPING.md`](BOARD_MAPPING.md)。

## 1. 系统结构

圆形**载板 PCB**（Ø≤110mm）承托一块 **Waveshare ESP32-P4-WIFI6** 开发板，经两排 1×20 / 2.54mm 排针对插。

- **开发板负责**：ESP32-P4 计算 + ESP32-C6 联网 + 32MB PSRAM + microSD + **MIPI-DSI 屏** + **MIPI-CSI 相机(OV5647)** + **板载音频(ES8311+NS4150B+麦+扬声器座)**。→ 这些**载板都不做**。
- **载板负责**：电池 + 电源管理 + 三路电机驱动 + 编码器接口 + IMU + 环境光接口 + 对外焊点/连接器，并从 40-pin 把空闲 GPIO 引出。
- **载板不走高速线**（MIPI 在开发板上）。

## 3. 电源架构

```
1S LiPo ──[DW01A+FS8205A 保护]── VBAT ──┬── IP5306 ──(2.1A boost)── 5V_SYS ──[SS34]── VSYS(开发板)
   ▲                                     │        └─(2.4A 充电)──◀── 充电口(Micro-USB/Type-C)
   │ JST-PH                              └── MT3608 ──(boost 5~6V)── MOT_6V ──[PTC]── TB6612 VM
3V3(开发板稳压) ──回灌── IMU / BH1750
```

- **供电注入点 = 开发板 VSYS**（板载稳压；不灌 VBUS 以免回串 USB-C）。
- 充电由 IP5306 完成（输入充电口）；电量经 IP5306 I²C 寄存器读取。
- **功耗粗算**（P0）：待机 ~1–1.5W；带运动峰值 ~3–5W。3000mAh@3.7V≈11Wh → 待机数小时、连续运动 ~2–3h。

## 4. 电机与保护（硬需求）

- **拓扑**：2×TB6612FNG。#1 驱 M0(A)/M1(B)，#2 驱 M2(A)，B 路备用。`MOTOR_STBY` 两片并联。
- **电池保护**：DW01A + FS8205A 完整保护链（过充/过放/过流/短路）。
- **电机堵转过流保护**（「卡住不能烧电池」）：
  1. 电机轨串 **PTC 自恢复保险丝**（持续堵转电流触发断开）；
  2. 电机轨 **shunt → ADC(`MOT_ISENSE`)** 采流；
  3. 固件检测「电流高 + 编码器不动」→ 拉低 `MOTOR_STBY` **急停**；
  4. TB6612 自带热关断 + DW01A 过流为最后兜底。
- **去耦**：电机轨入口 **470~1000µF** bulk；每片 TB6612 VM **100µF + 0.1µF**；3V3 各 **0.1µF**。

## 5. 传感

- **QMI8658C**（SPI + INT，顶替 ICM-42688-P，同 LGA-14）：放载板靠中心、远离电机磁场；标准 SPI 去耦。
- **BH1750FVI**（I²C1）：可贴外壳内壁感知环境光 → 载板留 4Pin JST-SH 引出，不强焊。
- **无悬崖传感器**（本版）。

## 6. I²C 规划（开发板两路硬件 I²C）

- **I²C0 = IO7/8**：板载 ES8311/触摸等用，载板不抢。
- **I²C1 = 两空闲脚（GPIO20=SDA / GPIO21=SCL）**：外部传感器（BH1750；可选从载板侧读 IP5306）。分流避免与音频/系统总线相互干扰。

## 7. 与开发板的接口

**ESP32-P4-WIFI6 实测尺寸（Waveshare 官方尺寸图 `enclosure/esp32p4wifi6_dimensions.jpg`）**：
板宽 **21.00mm**、安装孔距长 **71.05mm**、含 C6 模组总长 **~89mm**、厚 **1.61mm**、排针 **2.54mm**、
**两排针行距 ~17.8mm**（Pico 式，沿 21mm 宽边）、C6 模组段外伸 18.27mm。

- 两排 1×20 / 2.54mm 母排座，**行距 17.8mm**对插（载板已按此放置；装板前用实板卡尺复核行距与孔位）。
- 注入 `VSYS`、共 `GND`、回灌 `3V3`；空闲 GPIO 按 `BOARD_MAPPING.md` 引出。
- 开发板双面贴片 + 底端 USB-C + 中部 microSD + 右端 C6 模组天线 → 载板对应区**挖孔/让位/避高件**；矮件（0402/0603）可置于板下（排针架空 ~8–11mm）。
- **中部挖孔 15.5×59mm**（两排母排之间，让开发板底面元件/DISPLAY·CAMERA FPC/microSD 穿过；实板实测值，载板已开 Edge.Cuts 内框）。15.5<17.8 行距、59<71 孔距 → 与官方尺寸自洽。
- 板长 ~89mm：开发板近乎横贯载板，周边器件主要落两侧月牙区（电机→左、电源/传感→右）。
- **载板外形 = 圆角矩形（圆四边切平），尺寸不固定**：载板已与外壳解耦，无外壳尺寸上限，板框在「保电气功能+可靠性+可布通」前提下由 goal 循环**尽量缩小**（起点上界 92×92，真值见 `pcb/circuit/geom.py`）。板上留 **≥4 个 M3 孔**（脚本自动落点、导出孔位）供后续固定支架围着板设计 + 中部 15.5×59 挖孔。**详见 [`05_PCB板卡使用说明.md`](05_PCB板卡使用说明.md)**（机械/孔位/连接器/制造/装配/复核清单全在那）。
- **装板前用卡尺复核**：两排行距(~17.8mm，官方图未直接标注)、挖孔 15.5×59、孔位。

## 8. 待决（承接 docs/04 待决问题）
- Q3 P4 是否 v3.x 硅版（影响 CSI/ISP，不影响载板电气）。
- Q4 屏尺寸/分辨率（影响外壳与 LVGL 预算，不影响载板）。
- Q5 预算 / 是否 Rev B。
- 载板板框 L×W + 孔位 = 待开发板 STEP/实测锁定。

## 9. 与 NanoSoul-Alpha / MochiPet 基线的取舍

| 项 | Alpha/MochiPet | 本项目（当前 docs 为准） |
|---|---|---|
| 悬崖 | VL6180X ToF | **去掉**（IMU 兜底，本版减负） |
| 电源 | 独立充电IC+5V/6V boost+Qi+power-path | **IP5306 + MT3608 + DW01A/FS8205A**（当前 docs 体系） |
| 无线充 | Qi RX | **不做** |
| 形态 | MochiPet costume/pogo/磁吸/隐私键/双麦 | **不做**（V1 一体式） |
| 音频 | 载板做 codec | **用开发板板载**，载板不做 |
