## 板子制造参数（下单页填这些）
- 层数 **2 层**；尺寸 **94 × 92 mm**；板厚 **1.6 mm**；铜厚 1oz；表面处理 HASL 无铅(或沉金)。
- 外形：圆角矩形（Ø108 圆四边切平），**最外围有 3mm 白边**（铜距外缘 ≥3mm，留给铣外形）。
- **⚠️ 中部有 15.5 × 59 mm 矩形通槽（铣槽 routed slot）** —— 它在 Edge.Cuts 上，务必让厂家**按内框铣穿**（开发板底面件/FPC/microSD 从这穿过）。下单时若系统没自动识别内槽，备注说明。
- 孔：6 个 NPTH 非金属化安装/定位孔（4×M3=3.2mm 立柱、2×M2=2.2mm 定位）。
- 最小线宽/间距：本设计 ≥0.2mm，常规工艺即可。

## ⚠️ 贴片前必须确认的几件事（不看会装错！）
1. **开发板不在本 BOM 里**。载板只贴自己的件 + 两排母座 J3/J4（开发板出厂另插，焊好母座后手插）。
2. **THT 插件件**（`J1` JST-PH、`J2`/`J5`/`J6`/`J7` 2.54 排针、`J3`/`J4` 1×20 母座）—— **JLC 的 SMT 贴片不装这些**。要么选「**手工焊接/THT 装配**」加项，要么收板后自己焊。其中 **J3/J4 母座是关键**（开发板靠它对插，行距 17.8mm），建议自备并手焊以保证行距/可插拔。`J8` 是 SMD（JST-SH），SMT 能贴。
3. **`D1/D2/D3` 指示 LED 已定**：红色 0805 `C84256`(JLC 基础库)已填进 BOM。若想换电量条配色改 LCSC 即可。
4. **待确认料号已逐项查实并填进 BOM**（详见 `report.xlsx`「详细解决方案」）：`C8`→`C4747956`(原 RYVP25V470UF8*10 查无此件已换)、`L1`→`C2047296`、`L2`→`C703091`、`J1`→`C131337`、`J8`→`C495539`、`F1`→`C207025`(0805L150)、`SW1`→`C720477`(TS-1088，原 C&K 太贵已换)。剩 14 行普通 R/C 仍 LCSC 留空 → JLC 按「值+封装」自动匹配，重点核对：
   - **`R7 = 0.05Ω 0805`**（电流采样 shunt，要低阻/功率件，别匹配成普通 0.05Ω）。
   - **`L1/L2` 库存薄**（尤其 L1），下单前查 JLC 实时库存；`L2` 对电机满载电流偏紧。
   - **电机轨已改 5.5V**(R5 91k→82k)，给 `F1` PTC 的 6V 耐压留余量。
5. **极性件旋转必核对**：BOM「类型/备注」列标了「极性/旋转核对」的件（所有 IC、二极管 D1-D5、电解 C8）。**上传 CPL 后看 JLC 预览，逐个核对 pin1/阴极/正极朝向** —— KiCad 与 JLC 库朝向常差 90/180°，这是 PCBA 最容易错的点。
6. **坐标对齐**：Gerber/钻孔/CPL 都用同一(绝对)坐标系导出（CPL 的 Y 为负是 KiCad 约定，与 Gerber 一致）。在 JLC 预览里确认器件落在板内对位即可。
