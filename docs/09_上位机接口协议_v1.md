# 09 · 上位机接口协议 v1（冻结）

> NanoSoul 与电脑配套上位程序之间的接口。**本文件是协议真值源**，固件侧实现见 `components/companion/`。PC 端程序（可视化陪伴面板、用户状态长期分析）是后续独立工程，本仓库只交付协议 + 固件端点。
>
> 目的：让上位机看到用户状态与机器人内部状态，服务「陪伴感知 / 情绪价值」——在席/离席、被注视时长、互动次数、情绪流转等都从事件流出，供 PC 端做长期分析与呈现。

## 传输

- `ws://nanosoul.local/ws?token=<companion.token>` —— **仅局域网**。token 来自 SD 配置 `companion.token`，不匹配直接拒绝握手。
- 文本帧 = UTF-8 JSON；二进制帧 = JPEG 快照。
- 通用信封：`{"v":1, "type":"<kind>", "ts":<开机毫秒>, ...}`。
- **前向兼容铁律**：收到未知 `type` 必须忽略，不得报错。字段只增不改语义。

## 机器人 → PC

### `state`（1Hz 全量心跳）
```json
{
  "v":1, "type":"state", "ts":123456,
  "soul":"ENGAGE", "emotion":"waiting",
  "face":{"present":true, "cx":-0.12, "cy":0.05, "area":0.09, "frontal":0.71},
  "motion":{"intent":[0.0,0.0,0.10], "duty":[0,-102,102], "enabled":false},
  "enc_rpm":[0,0,0], "current_ma":null,
  "net":{"ip":"192.168.1.42","rssi":-58},
  "llm":"idle", "voice":"idle",
  "heap":210000, "fps":{"render":18.0,"detect":6.2}
}
```

### `event`（即时）
```json
{"v":1,"type":"event","ts":123456,"name":"soul_transition","data":{"from":"IDLE","to":"APPROACH"}}
```
`name` 取值与 `data`：
| name | data | 陪伴分析含义 |
|---|---|---|
| `soul_transition` | `{from,to}` | 行为状态流转 |
| `face_present` / `face_lost` | `{}` | 主人在席 / 离席（陪伴在席率） |
| `gazed` | `{}` | 一次「被注视」触发（专注互动） |
| `wake` | `{}` | 语音唤醒（主动交互次数） |
| `llm_reply` | `{text}` | 一轮对话回复文本 |
| `fault` | `{text}` | 故障（堵转/错误） |
| `selftest_item` | `{name,result,detail,round}` | 自检项结果 |

> 用户状态类分析（在席时长、被注视累计、互动频次、情绪分布）由 PC 端从上述事件流聚合，固件只负责如实上报，不在设备侧做长期统计。

### `snapshot`（二进制）
一帧 JPEG（当前检测帧，300×480），响应 `get_snapshot`。

## PC → 机器人（命令）

每条命令 `{"v":1,"type":"<cmd>","id":<n>, ...}`，机器人回 `{"type":"ack","id":<n>,"ok":true|false,"err":"..."}`。

| cmd | 字段 | 动作 |
|---|---|---|
| `ask` | `{text}` | 文字问答，复用 LLM 链路；回复走 `llm_reply` 事件 |
| `set_emotion` | `{name, mode:"now"|"fade"}` | 表情覆盖，10s 后回归状态机 |
| `teleop` | `{vx,vy,wz,ttl_ms}` | 遥控运动，仅 `motion.enabled` 生效，ttl 到期自动停 |
| `get_snapshot` | `{}` | 回一帧 JPEG 二进制 |
| `estop` | `{}` | 进 FAULT，急停锁定 |
| `clear_fault` | `{}` | 解除 FAULT |
| `config_reload` | `{}` | 重读 SD 配置 |
| `set_overlay` | `{on:bool}` | 开关 debug HUD |
| `selftest` | `{}` | 触发一轮自检 |

## 安全 / 边界

- LAN only，token 鉴权；不暴露公网。
- `teleop` 在 `motion.enabled=false`（未接轮）时 `ack ok:false err:"motion disabled"`。
- 破坏性/外部动作（此协议内仅 `estop`）立即执行；其余命令幂等或可回退。
