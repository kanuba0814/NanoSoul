# NanoSoul 载板 PCB —— 用户累积的要求（设计真值）

把这块板从 0 画到位需要满足的全部约束。逐条是用户在多轮里明确拍板的。权威细节仍以 `docs/02_硬件规格.md`、`docs/BOARD_MAPPING.md`、`docs/05_PCB板卡使用说明.md` 为准——本文件是"一句话需求"时不用回翻就能对齐的清单。

## 这块板是什么（架构）
- **载板（carrier）**，中部竖插 **Waveshare ESP32-P4-WIFI6** 开发板（基础版，Pico 长条 21×~89mm，双面贴片，两长边各 1×20/2.54mm 共 2×20 边沿排针）。
- 载板用**两排 1×20 母座(PinSocket)** 对插开发板，行距 **17.8mm**(Pico 700mil)，朝上；开发板公针朝下插入 → 可插拔。
- **供电注入点 = VSYS**（载板把 IP5306 的 5V 注入 VSYS；不灌 VBUS）；3V3 由开发板回灌给载板传感器。
- 屏/相机/音频/联网/microSD/PSRAM/C6 **都在开发板上，载板不做、不走高速线**。
- 开发板底面元件 + 中部 FPC/microSD 落进载板**中部 15.5×59 矩形挖孔(铣槽)**；USB-C 与 C6 天线悬在板外。

## 板上要做的电路（功能块）
- **电源/保护**：1S LiPo(JST-PH) → **DW01A+FS8205A 过充/过放/过流/短路保护链**（硬需求）→ VBAT → IP5306(**必须 I²C 版 LCSC C488349**，2.4A 充+2.1A 5V 升+按键+I²C 电量) → 5V_SYS →(SS34)→ VSYS；MT3608 升压给电机轨。充电口 J2。
- **电机**：3×N20(6V,带编码器) 经 **2×TB6612FNG**（3 路 + 共用 STBY）；3×6P 电机连接器 J5/J6/J7(M0/M1/M2)。
- **电机堵转过流保护**（硬需求）：电机轨串 **PTC 自恢复保险丝 + 低边电流采样(shunt→ADC MOT_ISENSE)**；固件检测「高电流+编码器不动」→ 拉低 MOTOR_STBY 急停。**卡死电机不能烧电池**。
- **传感**：ICM-42688-P IMU(SPI+INT)；BH1750 环境光(I²C1，可贴壳，J8 JST-SH 4P 引线)。**本版无悬崖传感器**（IMU 兜底 lift/碰撞）。
- 对外连接器：J1 电池、J2 充电、J5/J6/J7 电机×3、J8 环境光、J3/J4 开发板母座。

## I²C / 引脚
- 开发板**两路硬件 I²C**：I²C0=IO7/8(与板载 ES8311 音频共用，**载板不碰**)；**I²C1 另选两空闲脚**给 BH1750。
- 可用 GPIO 池见 BOARD_MAPPING；避开 IO7/8(I²C0)、IO9~13/53(音频 I²S)、IO39~44(microSD)、RXD/TXD(调试)、34/36(背面 strap 备用)。
- 引脚与布局**协同**：M0/M1 信号在左排 J3、M2/光照 I²C1 在右排 J4 → 信号几乎不跨中线（唯 VMOT_F/MOT_RTN 大电流跨中线，人工/route2 加宽）。

## 机械 / 板框（硬约束）
- **装进 ≤110mm 球壳** → 板框 = **Ø108 圆 clamp 成矩形**（四角留 Ø108 圆弧）。当前 **94×92mm**（切边左右 7、上下 8mm）。**不能做圆角矩形**（对角线超球径）。
- **最外围一圈 ≥3mm 白边**（工厂铣外形余量）：铜+器件焊盘距**最外缘** ≥3mm；中部挖孔是内部，0.4mm 铜净空即可。
- **6 个孔全在板内可钻**：4×M3 立柱孔(规则 54×82 矩形附近) + 2×M2 定位（上下中）。旧坑：钉在 Ø108 圆外钻不出。
- 板厚 1.6mm FR-4，2 层；铜到外缘 ≥3mm、到挖孔 ~0.4mm。

## 器件/库纪律
- **不许占位符**：非库存件用 **easyeda2kicad 按 LCSC 号**下到 `pcb/libs/`（ICM-42688-P C1850418、IP5306-I²C C488349、TB6612FNG C141517、MT3608 C84817、DW01A C351410、FS8205A C908265、BH1750 C78960、SS34 C908680）。库存件用 KiCad10 自带库。
- **不漏画外围**：电池保护链、电机过流保护、去耦(470µF 电机轨+每片 TB6612 VM 100µF/0.1µF)、SS34 防反、PTC 都要在板。
- BOM 带 LCSC 号便于嘉立创打样贴片。

## 完成度（Definition of Done）
1. PCB **DRC 0 violations / 0 unconnected / 0 短路**；2. 原理图 **ERC 0**（网表为真值源，见 gotchas #11）；
3. **3mm 白边**达标；4. **17.8 行距** + 挖孔 15.5×59；5. **J2/J7 离 J4** 有净空；6. **6 孔在板内**；
7. **丝印干净**（无叠字、字高≥0.8、无 F.Fab 长文本、位号不压焊盘/不越边）；8. 保护链+过流保护在板。

## 协作红线（CLAUDE.md）
- 三级过滤：**能用现成不写 → 能 AI 不手搓 → 才手搓**；乐鑫官方/支持 P4 的现成件优先。
- **板外纪律**：共享脚本/任务默认板外可跑，不含 flash/monitor/JTAG（只 Captain 有板）。
- **commit 只在被明确要求时**；改引脚/总线先更 BOARD_MAPPING 再改电路。
- **平等口吻**：文档/注释/commit 不用「新人入门/onboarding/第一个 PR」等措辞。
- AI 的一切产出（原理图/布线/电平/上电顺序）**人必复核**；关键尺寸读厂商 datasheet / 实板卡尺，不臆造。
