# 14 · 底盘校准与轮速闭环 v1

> 三全向轮（GA12-N20 118:1 + Ø~70mm 全向轮，120° 一后两前）从「开环 duty」升级为
> 「每轮转速闭环 + 里程计」的设计与校准记录。协议基线见 docs/13；轮角/引脚真值见
> `components/motion/motion.c` 与 `docs/BOARD_MAPPING.md`。

## 1. 架构

```
意图 (vx,vy,wz ~[-1,1])
  → motion_ik()          纯 IK + 峰值归一化（components/motion/motion.c，不变）
  → apply 桥 ±1023        闭环开: wheel_ctrl_apply()   闭环关: app_face_motor_apply()
  → app_wheelctrl 50Hz    sp = cmd/1023 × rpm_max（电机轴 rpm）
       每拍: 自差分 encoder_count → 瞬时 rpm → EMA(0.4)
             设定值斜坡(move.ramp_ms 满量程) → 死区(sp_deadband_pct)
             duty = ks·sign(sp) + kv·sp + PI(sp−meas)   ← espressif/pid_ctrl
       同拍: odom_step() 里程计积分 (x,y,θ) → telemetry
  → motor_set()
```

- **前馈担主力，PI 只修残差**：kS（静摩擦死区）/kV（斜率）来自 A2 扫描；积分对输出的
  贡献限幅 ±120 duty（`WC_TRIM_I_MAX`，≈满速 12% 修正权限）。夹太松会在斜坡期灌满
  积分导致大超调（pid_ctrl 的 `max_integral` 夹的是误差累计和 rpm·拍，刻度=上限/ki）。
- **反馈不走 `encoder_rpm()`**（100ms 窗+EMA 滞后太大），控制环内 50Hz 自差分。
  分辨率：满速 ~150 计数/拍；10% 速度 ~15 计数/拍（±7% 量化，EMA+PI 抹平）。
- **驱动权单一**：motor_test / wheel_sp 抢权统一走 `motion_set_apply(NULL)` +
  `wheel_ctrl_halt()`，归还走 `app_face_motor_bridge()`（自动选闭环/开环桥）。
- **急停链不变**：堵转 FSM（app_sense.c）拉 STBY 时 wheelctrl 冻结并清积分，
  恢复后干净起步。闭环顶着堵转把 duty 拉高反而让「大 duty + 零速 + 大电流」判据
  更快触发。
- **开环回退**：`motion.calib.closed_loop=false` → 原始 duty 直通（改配置重启即回）。
  此时 wheelctrl 仍以测量模式跑（只算里程计，不碰电机）。
- **里程计**（components/motion/odom.c，纯函数）：FK 是 motion_ik 的解析逆，
  `vᵢ = Δ计数/3304 × π·wheel_d`，中点航向积分。口径=cm 级位移预算
  （docs/12 approach_budget_cm），辊子打滑 ±8% 级误差，不做全局定位。

## 2. 配置（config.json `motion.calib`，代码默认值兜底）

| 字段 | 默认 | 说明 |
|---|---|---|
| `closed_loop` | false | 闭环开关；**A2/A3 校准回填后才翻 true** |
| `wheel_d_mm` | 70.0 | 有效轮径；A3 直线滚动实测修正 |
| `body_r_mm` | 56.0 | 轮心到中心距；CAD 占位，A3 自旋实测修正 |
| `rpm_max` | 15000 | 电机轴满指令转速（三轮满 duty 实测最小值 ×0.95） |
| `ks[3]` | 0,0,0 | 每轮静摩擦前馈（duty），A2 拟合 |
| `kv[3]` | 0.0682×3 | 每轮速度前馈（duty/rpm），A2 拟合；默认=1023/15000 名义值 |
| `pid` | kp .05 / ki .02 / kd 0 | 每拍口径；一阶模型仿真 稳定~260ms/超调~15% |
| `sp_deadband_pct` | 3.0 | 设定值死区（% rpm_max），防零点抖鸣 |

## 3. 协议增量（docs/13 风格，前向兼容）

命令（仅 TEST 模式；FAULT 拒绝；参数夹限）：

```json
{"type":"wheel_sp","sp":[3000,3000,3000],"ms":1500}   // 闭环阶跃（PID 整定）
{"type":"pid_set","kp":0.05,"ki":0.02,"kd":0}          // 在线改增益（不落盘）
{"type":"odom_reset"}                                   // 里程计清零
```

sense 帧新增字段：`"sp":[rpm×3]`（斜坡后设定值，开环恒 0）、
`"odom":[x_mm,y_mm,th_rad]`。hwinfo `range` 新增 `closed_loop/wheel_d_mm/body_r_mm/rpm_max`
（生效中的配置）。

板上 sim 自检（SELFTEST 模式，纯逻辑）：`fk_roundtrip`（ik→fk 互逆）、
`odom_sim`（方形闭合+整圈）、`wheelctrl_sim`（收敛/堵转/重启/死区）。

## 4. 校准 runbook（顺序：方向 → 前馈 → PID → 几何）

通道：**companion WS**（电机占 IO24/25 后 USJ 不可用）；日志 UART0/CH343。
Claude 驱动命令与采数，Captain 做物理操作。

### A1 方向/映射（架起，轮悬空 → 落地验收）
1. 逐轮 `motor_test m=i duty=+460 ms=800`，记录：是哪个物理轮（后/左前/右前）、
   俯视转向、`enc` 计数符号。
2. 对照 `motion.c` 轮角约定（+x 前、0°=后轮?——以实车为准）修 `MOTION_WHEEL_ANGLE_DEG`
   的 M0/M1/M2 分配与符号 → rebuild → reflash。
3. 落地 teleop 验收：`wz>0` 逆时针自旋、`vx>0` 前进、`vy>0` 左横移。三项方向全对才过。

### A2 前馈扫描（架起，电池供电）
```
python3 tools/testhost/calib_sweep.py --ws <ip> --token <token>
```
逐轮双向 ±15..100% duty 阶梯 → 拟合每轮 kS/kV + 满 duty 转速 → 按脚本输出回填
`ns_config.c` 默认值与 SD config（`rpm_max` 取三轮最小 ×0.95）。双向不对称 >10% 要留意
（接线/机械偏磨）。

### PID 整定（架起；改 SD `closed_loop:true` 或直接改默认值重刷）
1. `sense_rate hz=50`，`wheel_sp sp=[0.3,0.3,0.3]×rpm_max ms=2000` 起步，观察 sense
   的 `sp` vs `enc.rpm`。
2. 阶跃 30%→60%：`pid_set` 在线调。验收：稳定 <300ms、超调 <20%、低速（10%）无振荡。
3. 三轮一致性：同设定值下三轮稳态 rpm 差 <3%。

### A3 几何（地面）
1. **直线**：`odom_reset` → teleop `vx` 慢速走到 odom x=500mm 停 → 卷尺量实际
   → `wheel_d_mm ×= 实测/500`。往返各一次取平均。
2. **自旋**：`odom_reset` → `wz` 慢速转到 odom θ=6π（3 圈）→ Captain 数实际圈数
   （胶带贴地做记号）→ `body_r_mm ×= 3/实际圈数`。
3. 回填 → 复测一轮。

### 总验收
- 1m 前进 / 1m 横移 / 360° 自旋，odom vs 卷尺/记号误差 <8%。
- 堵转：手按住一轮 1s → FAULT 急停（事件 `stall`）→ 松手清障恢复。
- SELFTEST 模式全绿（新增三项 sim 在列）。

## 6. 已知风险与口径

- 低速端（<10% rpm_max）编码器量化明显，靠 EMA+死区；巡航段无碍。
- USB 供电与电池供电 kV 有偏差——**校准以电池为准**，残差 PI 吸收。
- kv 标定偏差 >12% 时积分权限（±120 duty）不够补满速段余差——重跑 A2 而不是放松
  `WC_TRIM_I_MAX`。
- 里程计误差口径 ±8%（辊子打滑+有效轮径波动），只用于短程位移预算。
- `pid_set`/`wheel_sp` 都不落盘；定稿参数进 `ns_config.c` 默认值 + SD 模板。
