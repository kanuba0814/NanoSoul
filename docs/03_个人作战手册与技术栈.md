# NanoSoul 个人作战手册与技术栈

> 本文档替代原《03_三人分工与技术栈》。
> 团队模型：**单人负责制 + AI 协同 + 杂事外包**。
> 开发铁律：**能用现成不写 → 能 AI 不手搓 → 才轮到手搓**。
> 一切以**比赛获奖**为最高目标；功能与完成度冲突时，**砍功能保完成度**。

---

## 1. 角色与开发铁律

### 1.1 单人负责制
- **你 = 全栈 Owner + 整机集成**：结构、PCB、底层固件、传感器/运动、显示/表情、AI/Agent、WebUI、OTA、整机联调，全部由你做技术决策。
- **被消除的是协调开销，不是劳动量**：不再维护三方接口契约、不再每周三人集成日。
- **真人只接杂事**（3.3）。

### 1.2 三级决策过滤（每写一行代码前先过一遍）
1. **能用现成不写**：先查乐鑫官方/官方背书组件是否已支持 P4，能配置即用的绝不重写（清单见第 4、5 节）。
2. **能 AI 不手搓**：现成没有的，先让 AI（Claude / Claude Code）出，人复核（第 6 节）。
3. **才轮到手搓**：只有"现成没有 + AI 不可靠 + 关系成败"的，才亲手写（自研清单见第 7 节）。

### 1.3 承重假设与最大风险
- **承重假设**：现成件 + AI 能扛下"广度"。这次复用调研已证实大部分成立。
- **第一风险 = 完成度/带宽**：完成度是本赛道得分第一杠杆，单人=三倍广度。缓解：现成优先、功能砍到 P0、核心集中投放。
- **最难 AI 化的一环 = ESP-DL 表情/手势模型训练**：官方无现成情绪/手势模型，须自训；缓解：人脸/人形检测先用现成模型起步，表情/手势列 P1。

## 2. 比赛获奖第一性原则（来自策略报告）

1. **P4 必须是"主角"不是"前端机"**：感知决策逻辑（何时靠近/退后/表情反馈）必须在 P4 本地完成；云端 LLM 只做深度对话，**不进实时决策回路**，否则触违规红线。
2. **本地 ESP-DL 视觉推理 = 不可妥协的内核**：规避"主要功能跑在第三方芯片=违规"红线、命中"芯片特性利用"的唯一硬证据。
3. **断网演示 = 杀手锏**：现场断 WiFi，本地感知决策闭环照常跑，再连网展示云端对话与工具调用。
4. **P4 vs S3 三件套**：MIPI-CSI 视觉 + MIPI-DSI 大屏 + RISC-V 算力，每项都备"换 S3 做不到"的量化对比。
5. **主报选题一（嵌入式边缘AI应用，P4）**，文档说明同时覆盖选题二（人机交互）、选题三（运动控制）以体现系统完整性。

## 3. 工作分配

### 3.1 你亲自负责、不可外包的核心
- 系统架构与所有技术决策
- PCB 关键布局布线（电源分区、地、MIPI 高速线、电机大电流）
- 实物 bring-up 与排错（上电、示波器/万用表、逐外设验证）
- **本地感知决策状态机的逻辑设计**（参赛差异化内核）
- 整机联调与现场演示稳定性

### 3.2 现成件 / AI 替你扛的（详见第 4–6 节）
- 视觉、语音、表情 UI、云对话、摄像头、编码、联网 → 官方现成件
- 固件骨架、驱动、UI 代码、LLM 对接、原理图逻辑、BOM、文档 → AI 出，人复核

### 3.3 可分配给真人的杂事
- AliExpress 下单/跟单/收货、3D 打印件后处理装配、贴片焊接帮手/返修、demo 视频拍摄剪辑、PPT 美化/文档排版、测试记录、报名材料整理

## 6. AI 协同用法（能 AI 不手搓）

- **Claude**：原理图逻辑/网表、器件选型/封装匹配、BOM、datasheet 问答、ERC/DRC 解读、设计评审、文档。
- **Claude Code**：固件骨架、BSP、驱动、LVGL/表情代码、LLM 对接与 tool schema。PC 模拟器闭环（SDL backend + 无头截图 PNG）做 UI 迭代。
- **嘉立创EDA AI 扩展**（eda-copilot 多模态 / Kimi）：原理图页面内查询、选型辅助。
- **铁律**：AI 一切产出**人必复核**——关键布线、电平、电源、上电顺序不能赌 AI。

## 10. 必须先学的内容（按顺序，边学边出板）

- **第 0 步**——本板用得到的电路最小集：分压/上拉下拉、I²C 上拉、去耦电容、电平匹配（**P4 GPIO 绝对最大 3.6V，5V 是硬禁区**）、H 桥逻辑、Boost 升压、电池保护链。不啃整套模拟电路。
- **第 1 步**——嘉立创EDA专业版上手：B站"国一学长 保姆级"入门篇，先做一块最简单的板练手。
- **第 2 步**——能看懂并复核 AI 产出的原理图：读网表、跑 ERC、核对封装管脚。
- **第 3 步**——关键布局布线（亲手练，最不能省）：电源分区、地、MIPI 高速线、电机大电流。
- **第 4 步**——实物 bring-up：万用表/示波器、分块上电、逐外设面包板验证。

**时间预期**：即便 AI 帮出原理图，从零到第一版载板边学边做约 **2–3 周**。
