# 洞洞板焊接版（perfboard 分支）

> **定位**：无 PCB 应急版的固化——不画 PCB、不全飞线，所有现成模块焊到一块洞洞板上。
> 引脚 = **当前 `main/` 固件真值**（`drv_motor.c` / `drv_encoder.c` / CLAUDE.md「固件」节），**固件零改动**。
> 与载板 PCB（`docs/BOARD_MAPPING.md` 载板节）是两套硬件，别互相纠正。

## 板子（唯一要买的东西）

**7×9cm 单面镀锡洞洞板（24 行 × 30 列，孔距 2.54 / 孔径 1.0）**，¥1~2。
手上的 5×5cm 是 18×18 孔，**开发板一排 20 脚跨 19 孔（48.26mm）物理插不下**，别硬凑。

## 布局一句话

开发板立插右侧（排母 col21/col28，行 3–22）；两片 TB6612 竖装中间（控制列 col18 朝开发板、功率列 col12 朝红轨）；INA219/QMI8658/BH1750 从上到下靠左；三个电机 6P 接口横排底边 row24。背面四横四纵 GND 网格 + col11 红轨(+5.9V) + col15 3V3 竖脊。

## 装前两个干插确认（不过关别下焊）

1. **TB6612 排距**：把模块脚插进洞洞板数孔。图按两列**隔 6 孔**画；若实为 7 孔 → 功率列(col12)与红轨/锡桥/电容**全部不动**，控制列改 col19，11 根控制跳线跟着挪 1 孔。
2. **模块引脚序**：INA219/QMI/BH1750 的孔区是**专用孔带**，若批次丝印顺序与图不同，按**名字**对位挪线即可，不影响其他走线。

## 焊接顺序

1. **排母 ×2**（col21/col28，先各焊对角 2 脚校平再焊满）。插上开发板核对锚点：**丝印 3V3 → (28,7)、IO52 → (21,3)**——插反必烧。核对完拔下。
2. **背面裸线母排/锡桥**（`wiring_table.md` B1–B30，先长后短）：GND 网格 → 红轨(col11，粗线) → 3V3 竖脊(col15)。裸线**只在同网孔上过**，图上没有的交叉一律不许出现。
3. **模块排针**：TB6612 ×2、INA219、QMI8658、BH1750 就位焊接。
4. **元件**：C1–C4（**电解电容 + 极接红轨 col11 侧**，卧倒朝南）、R1/R2（推荐，防上电抖动）。
5. **绝缘跳线** J1–J40：按 `subsystems.png` 一个分系统一轮焊，焊完一根在表上划一根。跳线中途可以压过任何焊点/裸线（绝缘），**两端孔位不能错**。
6. **电机接口** row24：直焊线或立 1×6 排针，线序 红白黑蓝绿黄。

## 板外接线

| 从 | 到 |
|---|---|
| 电池(JST) | XL6009 IN+/IN−（先空载调 **5.9V**！） |
| XL6009 OUT+ | INA219 模块**接线柱 Vin+**（≥0.5mm²） |
| INA219 接线柱 Vin− | 板上 **(11,2)** 红轨顶端（正面下线，粗线） |
| XL6009 OUT− | 板上 **(2,22)+(2,23)** 星地锚点（粗线，两孔都焊） |
| 电脑 USB | 开发板 USB 口 |

无总开关：断电 = 拔电池。充电：电池拔下来接 TP4056。

## 上电自检（沿用三电机接线图的红线）

1. 不插电机、不插开发板：电池上电，量红轨 (11,x)↔GND 网格 ≈ **5.9V**、任意两 GND 点 ≈ 0Ω。
2. 插开发板（USB 供电），量 3V3 竖脊 ≈ 3.3V；`i2cdetect` 应见 **0x40(INA219) / 0x23(BH1750) / 0x6A 或 0x6B(QMI)**。
3. 插电机逐个轮转（M2 自检固件），带载量 **桥 GND↔星地 ≈ 0V、VM-GND ≥ 5.5V**；编码器计数只在被驱动轮跳。
4. 任一步塌压 → 断电查那段干线（历史坑：地回流走了细线，VM 塌到 1.3V）。

## 定死的电气事实

- I²C 地址：INA219=0x40（A0/A1 默认）、BH1750=0x23（ADDR 焊死 GND）、QMI8658 ADO 焊死 GND（0x6A/0x6B 驱动自探）；上拉用模块自带（4.7k∥10k∥10k≈3.2k @100kHz 够用），板上不加。
- 编码器 A/B 开漏：上拉用**固件内部上拉**（已启用），板上不加；编码器 VCC 只许接 3V3。
- STBY 分置：桥#1=IO51、桥#2=IO52（固件两个都拉）。R1/R2 10k 下拉推荐但可省。
