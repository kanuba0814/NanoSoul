# enclosure/ — 外壳

球形外观，外径 **Ø≤110mm**。CAD 源文件（Fusion 360 / STEP）后续放这里。

## 与载板的机械约定

- **载板**：圆形 PCB，Ø≤110mm，与外壳同心。开发板（ESP32-P4-WIFI6）经两排 2.54mm 排针立在载板上。
- **让位**：开发板是双面贴片 + 底端 USB-C + 中部 microSD，载板对应区域**挖孔/让位**，排针高度需让开底面元件。
- **屏 / 相机**：MIPI-DSI 屏与 OV5647 经 FPC 插在**开发板**上，朝外壳正面（脸）开窗。屏向上倾斜 10–15°（见 `docs/01` 外形参数）。
- **贴壳传感器**：光照（BH1750）等可能贴在外壳内壁 → 载板留 4Pin JST-SH / 焊点引线过去，不强焊在载板上。
- **扬声器**：用开发板板载 MX1.25 座，喇叭装在外壳内合适腔体。
- **底盘**：三全向轮 120° 布置（N20 电机），轮孔/电机座在外壳底部。

## 开发板尺寸（Waveshare 官方尺寸图 `esp32p4wifi6_dimensions.jpg`）

ESP32-P4-WIFI6：**宽 21.00mm × 安装孔距长 71.05mm（含 C6 模组总长 ~89mm）× 厚 1.61mm**；
排针 2.54mm、两排行距 ~17.8mm、4 角安装孔（横向孔距 71.05mm）。
→ 载板中部需让出 ~21×89mm 给开发板，USB-C（左端）与 C6 天线（右端 18.27mm）处避高件/留净空。
→ **中部挖孔 15.5×59mm**（实测）让开发板底面元件/FPC/microSD 穿过；载板 Edge.Cuts 已开此内框。
