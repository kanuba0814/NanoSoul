# 02 硬件规格 附录：外设官方驱动/组件可用性（能用现成不写）

> 本附录追加到《02_硬件规格_P0.3》。**硬件选型本身不变**（已确认），本附录只标注每个外设"是否有乐鑫官方现成驱动/组件可直接用"，指导固件按"能用现成不写"开发。

## 1. 外设驱动可用性映射

| 外设 | 接口 | 官方现成件 | 状态 | 固件策略 |
|---|---|---|---|---|
| OV5647 摄像头 | MIPI-CSI | **esp_video + esp_cam_sensor**（自动检测 OV5647，自带 ISP） | ✓ 官方 | 改配置即用；CSI 供电需 LDO 2500mV |
| MIPI-DSI 屏 | MIPI-DSI | **esp_lvgl_port**（`lvgl_port_add_disp_dsi`，P4 PPA） | ✓ 官方 | 直接用；PPA 实验性，留软渲染回退 |
| BH1750 环境光 | I²C1 | **`espressif/bh1750`** 组件 | ✓ 官方 | 直接用 |
| 磁编码器 | GPIO/PCNT | **PCNT `rotary_encoder`** 示例 | ✓ 官方 | 移植，三路 PCNT 正交解码 |
| N20 电机 | PWM | **MCPWM `mcpwm_bdc_speed_control`**（带 PID） | ✓ 官方 | 单电机示例 → 改写三电机 |
| TB6612FNG | GPIO+PWM | 无需专用驱动 | — | LEDC/MCPWM + 方向 GPIO |
| INMP441 / 板载麦 | I²S | **ESP-SR AFE**（采集 + AEC/VAD） | ✓ 官方 | feed/fetch 流水线对接 |
| ES8311 codec | I²S | **esp_codec_dev** | ✓ 官方 | 直接用 |
| ESP32-C6（WiFi6） | SDIO | **esp_hosted**（板载已预刷） | ✓ 官方 | 按文档配；配网两芯手动适配 |
| **QMI8658 IMU**（已换型，原 ICM-42688-P 方案废） | SPI / I²C | **SensorLib**（社区最全，含片上 Tap/WoM 事件引擎）、`waveshare/qmi8658`（官方 registry，原始数据） | ✓ 现成 | 直接用（选型证据链见 06）；换型原因之一 = ICM-42688 无官方 SPI 驱动 |
| **IP5306 电源** | I²C | **无官方组件**（第三方 PMIC） | ✗ 自研 | 自写 I²C 读寄存器（含 0x00[1]=1 关自动关机）；仅载板阶段需要 |
| ~~ITR20001 悬崖~~ | — | — | **已砍**（04 D-017） | 本版无悬崖传感器，IMU 兜底 lift/碰撞 |
| MT3608 / DW01+8205A / SS34 | 模拟电源 | — | — | 纯硬件，无固件 |

**小结（随 QMI8658 换型与去悬崖更新）**：外设几乎全部有现成件——IMU 换 QMI8658 后用 SensorLib/官方 registry 组件，悬崖已砍；需自写固件的只剩 **IP5306**（载板阶段才用）。与《03 自研清单》同步修订。

## 2. 采购与硅版注意（更新）

- **优先采购 ESP32-P4 v3.x 硅版**：v3.x 修复了 ISP/MSPI 等若干问题（如 MSPI 上电唤醒 Load access fault、secure boot 校验异常），规避 MIPI-CSI 调试坑。
- **ESP-IDF 用 v5.4 / v5.5 稳定分支**（开发前回乐鑫赛题指引确认推荐版本）。
- **CSI 调试**：若 OV5647 偶发崩溃（如 0x102），开 `CONFIG_CAM_CTLR_MIPI_CSI_ISR_CACHE_SAFE` 等 IRAM 安全选项。
- ~~待确认项 Q1/Q2/Q3~~ **已解**（2026-07-05）：板 = Waveshare ESP32-P4-WIFI6，实到货 **v1.3 硅版**且整机 bring-up 已通过（docs/10 §6，CSI 靠 `ISR_CACHE_SAFE` + LDO_VO3@2500mV 补丁稳定）；板载麦经 ES8311（录音路径 `mic_record` 自检 FAIL 待查）。
