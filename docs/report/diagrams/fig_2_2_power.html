★ 单点星地锚点（XL6009 OUT−）
两套电源在此单点汇合共地；背面裸镀锡铜线做 GND 网格 + 底干线双股加粗，桥地经短锡桥就近回流
实测踩坑与解决：初版地回流走细跳线，电机一转，桥 VM 从 6.1V 塌到 1.3V（安培级电流在细线上压降约 5V）。改为宽短母排干线 + 单点星地后，带载 VM 稳定 ≥5.5V、桥地对星地≈0V。电机堵转保护：INA219 电流>350mA 且编码器不动持续 200ms → 拉低 STBY 急停（见运动控制小节）。
