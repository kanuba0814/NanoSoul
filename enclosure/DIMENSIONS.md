# NanoSoul 载板 — 尺寸报告（细画参考）

> 所有数值**逐一从已布线的 `pcb/output/NanoSoul/NanoSoul.kicad_pcb`**（Edge.Cuts / 焊盘 / 钻孔）提取核对，非估值。
> 顶视图见 [`pcb_dimensions.png`](pcb_dimensions.png)（生成器 [`model/pcb_dimensions_plot.py`](model/pcb_dimensions_plot.py)，直接读 kicad_pcb，可复跑）。
> 三维实体见 `pcb/output/NanoSoul/NanoSoul.step`（带元件）/ `NanoSoul-board-only.step`（纯板）。

## 坐标约定

- **原点 = 板心**（KiCad 页坐标 (150,100)）。下表「板心(x,y)」即相对板心。
- 顶视、朝元件面俯看：**+X 向右，+Y 向上**（= KiCad 页坐标的 −Y；KiCad 页内 +Y 朝下）。
- 装配到机身时，板平面的「上下左右」由你在 SolidWorks 里定向；本报告只给板内相对关系，origin-independent。

## 安装孔 M3 — 钻 **Ø3.2 mm** ×4（H1–H4）

> ⚠️ **非对称阵列**：缩板后孔由脚本「每扇区避器件最靠边」自动落点，不再是旧的 54×82 规则栅格。外壳螺柱**逐孔按下表坐标对位**（别假设对称）。

| 孔 | 板心(x,y) | 大致方位 |
|---|---|---|
| H1 | (−27.0, +41.0) | 左上 |
| H2 | (+32.0, +37.0) | 右上 |
| H3 | (−41.0, −27.0) | 左下 |
| H4 | (+27.0, −41.0) | 右下 |

- 四孔均在 **r ≈ 49 mm** 环上（孔壁离板边 ≈3–4mm）。
- 上/下边附近的孔（H1/H4）孔心离上下平边约 **5 mm** → 外壳螺柱别太胖，避让板边圆弧。

## 开发板母座 J3 / J4 — 1×20 立式排母，节距 **2.54 mm**，引脚孔 **Ø1.0 mm**

| 项 | 值 |
|---|---|
| 两排行距（J3↔J4，X 向） | **17.80 mm**（Pico 700mil） |
| 单排脚数 / 节距 | 20 / **2.54 mm** |
| 脚 1 → 脚 20 跨距 | **48.26 mm** |
| J3 列 X / J4 列 X（板心系） | **−8.9 / +8.9**（两列对称于板心 X） |
| 脚阵 Y 心 | 约板心上方 **1.27 mm** |
| → 开发板对插脚域包络 | **17.8 × 48.26 mm** |

> 开发板本体尺寸 **21.0 × ~89 mm（含 C6）× 1.61 mm**；C6 天线右伸 18.27 mm、USB-C 在左端（见 `README.md` 与 `esp32p4wifi6_dimensions.jpg`）。开发板**不在**载板 STEP 里（是竖插的独立件），按此脚域定位。

## 对外连接器 / 关键件（板心坐标，定线束/器件出壳位置）

| 位号 | 件 | 封装 | 板心(x,y) | 说明 |
|---|---|---|---|---|
| J1 | 电池 | JST-PH 2P | (−25.5, −7.2) | 左侧，电池线束 |
| J2 | 充电 | **板载 USB-C 母座** | (+16.3, +34.5) | 顶部，出壳口对此（旁挨 SW1/U2） |
| SW1 | 电源键 | 贴片轻触 | (+25.7, +26.8) | 顶部右，挨 USB-C |
| J5 | 电机 M0 | 1×6 排针 | (−41.8, +30.3) | 左上簇 |
| J6 | 电机 M1 | 1×6 排针 | (−36.3, +30.3) | 左上簇 |
| J7 | 电机 M2 | 1×6 排针 | (+13.2, +1.8) | 右中 |
| J8 | 光照(贴壳) | JST-SH 4P (SMD) | (+19.4, 0.0) | 右中，线束去顶窗 |
| U6 | IMU **QMI8658C** | LGA-14 | (−14.0, 0.0) | 贴挖孔左缘、近板心（离电机驱动较远） |
| C8 | 470µF 电解 | CP_8×10.5 | (−27.5, +19.5) | 左侧，最高件，在开发板脚域外 |

> 改料：IMU 由 ICM-42688-P → **QMI8658C(SPI)**；充电由 2P 排针 → **板载 USB-C 母座**；**板载光照 U7(BH1750) 已删**，光照只经 J8 贴壳引出。三电机 J5/J6/J7 仍 1×6 2.54 排针。

## 给细画的几条提醒

- **外壳安装柱用 4×M3**（H1–H4，**非对称、逐孔按上表坐标对位**）；H5/H6（M2）是定位/防呆销孔，按需用。
- H1/H4 孔心到上/下板边约 **5 mm** → 外壳对应螺柱/凸台别太胖，避让板边圆弧。
- 孔位非规则栅格 → `model/nanosoul_enclosure.py` 的螺柱坐标要按本表 H1–H6 逐一填（旧 54×82 已作废）。
- 中挖孔 15.5×59 正中：竖插开发板的底面元件、FPC、microSD 从这里穿过；外壳内**不要**有结构件挡这条中线。
- J3/J4 脚域 17.8×48.26 = 开发板对插基准面，机身定向以此为准。
