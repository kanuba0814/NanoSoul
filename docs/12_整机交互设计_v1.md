# 12 · 整机交互设计 v1（行为 / 情绪 / 运动语言）

> 目标：把整机全部感知硬件（相机 / IMU / 环境光 / 电流+编码器 / 触摸屏 / 麦克风 / 上位机链路）变成**可感知的生命感**，而不是一堆各自为战的 demo。
> 设计落在现有架构上（soul 状态机 / motion IK / face 表情 / telemetry 事件总线 / companion WS，见 00 §2–§3），每项都标注固件改动点与落地分期（§9）。协议改动全部走「只增不改」（09 铁律）。
> 本文是**行为真值源**：调阈值、加场景先改这里，再改代码。

---

## 0. 设计目标：什么让人觉得「智能」

不是算力，是**反应的质感**。七条原则，后文每个场景都能对回来：

| # | 原则 | 落点 |
|---|---|---|
| P1 | **即时回应**：任何刺激 → 可见反应 ≤300ms | 事件表情走 NOW；IMU/触摸走中断不轮询 |
| P2 | **动作有意图感**：先转头再移动、缓入缓出，像动物不像小车 | 运动原语带斜坡；朝向优先（§5） |
| P3 | **不机械重复**：同一刺激的反应带 ±15% 参数抖动与变体 | 原语参数抖动；反应变体表（§4） |
| P4 | **有内在状态**：行为随「精力/亲近感」慢变量可感知变化 | 情绪引擎两变量（§3） |
| P5 | **有短期记忆**：刚发生的事影响下一次反应 | 事件近因权重（§3.4） |
| P6 | **安静的存在感**：待机不是死机，有「呼吸」 | 微动作层（§2 R5、§4-S3） |
| P7 | **可预测的安全**：被抓住/抬起/卡住永远立刻停 | 反射层最高优先（§7），这是信任的来源 |

反面清单（做了会立刻显蠢）：反应延迟 >500ms；同一动作分毫不差地重复；无人时完全静止；被抬起还在蹬轮子；表情高频抖动切换。

## 2. 分层架构与意图仲裁（含 teleop 覆写修复）

现状问题：`soul_task` 每 100ms 无条件 `motion_set_intent()`，companion 的 teleop 会被立刻覆写（11 §6-C）。本设计以**仲裁器**根治，同时承载全部新行为：

```
输入事件 ──► 反射层 R0（同步路径，不过状态机）─────────┐
                                                        ▼
soul 行为层 R4 ──┐                          ┌──────────────────┐
teleop 租约 R3 ──┼─► intent 仲裁器（motion 内）│ 取最高优先活跃源  │─► IK ─► 电机
会话姿态 R2 ────┘   每源带 ttl 租约           └──────────────────┘
FAULT   R1 ─────► 恒零 + STBY 视情况
微动作  R5 ─────► 仅当 R2–R4 输出为零时叠加小幅调制
```

**优先级（高抢低，全部带租约超时回落）**：

| 级 | 源 | 说明 |
|---|---|---|
| R0 | 反射：堵转→STBY、LIFTED→轮全停、\|tilt\|>8°→停 | 绕过仲裁直接闸门，任何状态下生效 |
| R1 | FAULT / estop | 意图恒零，锁定至 `clear_fault` |
| R2 | 语音会话（LISTEN/THINK/SPEAK） | 平移为零，仅保留「朝人转正」的 wz |
| R3 | teleop（租约 = `ttl_ms`，缺省 300ms，续租式） | **修复点**：租约存活期内 soul 不得写 intent |
| R4 | 行为层（soul 状态机输出） | 现有 GAZED>RETREAT>APPROACH/ENGAGE>… |
| R5 | 微动作（idle 呼吸感） | 幅度 ≤R4 正常输出的 20%，可被一切打断 |

**固件改动点**：`motion_set_intent(source, vx, vy, wz, ttl_ms)` 加源与租约参数（旧签名保留为 R4 源的别名，兼容现有调用）；仲裁在 motion 组件内做，soul 不感知 teleop 存在。

## 3. 情绪引擎（轻量：两个慢变量，拒绝过度建模）

### 3.1 慢变量

| 变量 | 含义 | 升 | 降 | 可感知效果 |
|---|---|---|---|---|
| `energy`∈[0,1] | 精力 | 静置恢复 +0.1/10min；DOZE 加速恢复 | 运动/会话消耗；亮暗周期跟随 | 低→动作变慢变少、sleep 倾向；高→微动作频繁 |
| `social`∈[0,1] | 亲近感 | 每次正向互动 +0.05（gazed/对话/触摸） | 独处指数衰减 τ=10min | 高→接近更快更主动、tip 更热络；低+有人→更谨慎试探 |

两个都够「让人察觉它今天不一样」，又不至于调不动。初值 0.5，断电不保存（V1；持久化列 P2）。

### 3.2 表情资产现实约束

现有素材只有 **5 个 clip：waiting / o / sad / sleep / think**（各 4.5–15s 循环，07）。表达维度靠三件事扩展：**clip 选择 + 运动风格 + tip 文案**。`happy`、`blink`、左右瞥素材列 P1 补做（07 P3），本文场景先全部落在 5 clip 上。

### 3.3 表情切换规则（防抖是「不蠢」的底线）

| 优先级 | 类别 | mode | 规则 |
|---|---|---|---|
| E1 | FAULT → `sad` | NOW | 锁定至故障解除 |
| E2 | 事件瞬时（TAP/LIFTED/TOUCH/惊讶 → `o` 等） | NOW | **最短保持 800ms**，同类事件不重触发（1.5s 冷却） |
| E3 | 上位机 `set_emotion` | 按命令 | 10s 租约（现有），期间抑制 E4/E5、不抑制 E1/E2 |
| E4 | 会话（LISTEN/SPEAK→`waiting`、THINK→`think`） | FADE | 会话态期间稳定持有 |
| E5 | 基调（状态机+慢变量：DOZE→`sleep`、失落→`sad` 短暂、默认→`waiting`） | FADE | 切换最小间隔 2s |

同名表情不重发（避免 clip 重头播）；全部切换走现有 `face_set_emotion` 队列，无新机制。

### 3.4 短期记忆（近因权重，P5 原则）

固定长度事件环（最近 60s）：
- 60s 内第二次 `TAP` → 反应升级：退更远 + tip 从「呀」变「别敲啦」+ `social -0.1`。
- 刚结束 GAZED 回避 → 30s 内不再触发 GAZED（现有 1.5s 回避窗延长为记忆化冷却）。
- 刚被抬起放下 → 10s 内动作幅度减半（「惊魂未定」）。

实现 = soul 内一个 8 槽 `(event, ts)` 环形数组 + 查询函数，几十行的事。

### 3.5 注意力融合策略（视觉 × PC 状态 → 交互许可等级）

`pc_state` 是不依赖相机的第二路在场/注意力传感器。soul 每 tick 先算**交互许可等级**，再跑状态机——等级只调策略参数，不加新状态：

| 视觉 | PC 状态（新鲜） | 判定 | 许可等级 → 行为调制 |
|---|---|---|---|
| 有人 | `dnd` 或 `focus∈{work,meeting}` 且 active | 主人在专注 | **勿扰**：禁主动接近与邀玩，微动作频率 ×0.3，tip 静默；仅被直视（GAZED）或被触摸时回应 |
| 有人 | `meeting` | 开会 | **静默**：勿扰基础上运动全停（微动作也停），像「懂事地坐好」 |
| 有人 | idle_s > invite 阈值 | 主人闲着/挂机 | **主动**：允许 S17 邀玩，接近更积极（social 加成） |
| 有人 | `media` | 主人在娱乐 | **陪伴**：不打扰对话类 tip，允许 S19 节奏摆 |
| 无人 | active | 人在电脑前但不在视野 | **知情等待**：不演失落（S6 跳过 sad），朝屏幕方向偶尔张望 |
| 无人 | locked / idle 很久 | 真离开 | **休息**：加速进 DOZE（S18） |
| 任意 | 无 PC 信息（>15s 未更新） | 单源 | 回退 §4 纯视觉行为（v1 现状） |

**原则**：PC 状态只做「许可/克制」的调制器，**永不直接触发动作**（避免电脑上一个窗口切换就让机器人抽动）；触发权始终在视觉/IMU/触摸等物理刺激手里。dnd 的优先级最高——用户手动说安静，比一切推断都硬。

## 4. 交互场景库

格式：**触发 → 时间轴（运动/表情/tip）→ 退出**。角标 = 落地分期（§9）。阈值全部走 SD 配置（§8），此处为默认值。

### S1 开机仪式 ⁰
上电 → `sleep`（1.5s）→ `o`（睁眼，0.8s）→ 慢转 ±20° 张望一圈（接轮后）→ `waiting` + tip「NanoSoul ✓」。**第一印象即生命感**，且掩盖子系统启动时序。

### S2 发现人 → 迎接 ⁰′²
- 触发：`FACE_PRESENT`（IDLE/DOZE 中）。
- 时间轴：`o`(NOW, 0.8s) → wz 朝人转正（`wz=-0.8·cx`，现有）→ social>0.6 时向前 nudge 3cm¹ → `waiting`(FADE)。DOZE 中被发现：先「揉眼」（sleep→o 慢 FADE 1s）再执行，唤醒感。
- 退出：进入 S3/S4 常规循环。

### S3 陪伴驻留（ENGAGE 里的呼吸感）⁰′²
- 触发：ENGAGE 稳定 >5s。
- 微动作（R5，泊松间隔 8–20s 随 energy）：wz 正弦小摆 ±5°（1.2s）｜歪头 = 单侧 ±8° 停 0.5s 回正｜tip 偶发短句（「嗯嗯」「在呢」，频率低于动作，间隔 ≥60s）。
- **全程 area/cx 继续闭环**（人挪动就跟随转向）——微动作叠加不中断跟踪。

### S4 靠近 / 退后（sweet spot，现有行为的质感升级）²
- 现有：area<near_lo→APPROACH、>near_hi→RETREAT。升级三点：
  1. **先转正再平移**（|cx|>0.15 时只转不走，P2 原则）；
  2. 速度随偏差比例（远快近慢，到位前 0.3s 线性减速，不急停）；
  3. **APPROACH 位移预算**：单次 ≤15cm（编码器里程），预算耗尽仍不达标 → 停下歪头（tip「够不着…」），防无悬崖传感器坠桌（§7）。
- `d(area)/dt` 快速增大（人猛凑近）→ 插入 `o`(NOW) + 后退 nudge 5cm，比单纯 RETREAT 更「被吓到」。

### S5 凝视 → 害羞（现有增强）⁰′²
- 现有：frontal>0.7 持续 1.5s → GAZED，退避 vx=−0.5。
- 升级：退避改为 **retreat_shy 原语**（后退 6cm + 转开 15°，见 §5）+ `o`(NOW) + tip 变体池（「别一直盯着看啦」「我会害羞的」随机）；记忆化冷却 30s（§3.4）；social +0.05。

### S6 人离开 → 张望失落 ⁰′²
- 触发：`FACE_LOST` 持续 >2s（滤瞬时丢检）。
- 时间轴：wz 慢扫 ±30° 两个来回「找人」（3s）² → 找回 → S2；找不到 → `sad`(FADE, 5s) + tip「走了呀…」→ `waiting` → 计时进 IDLE。social 衰减开始计时。

### S7 被敲击 / 碰撞（IMU Tap）¹
- 单击：`o`(NOW) + 后退 nudge 4cm² + tip「呀」。60s 内第二次：退 8cm + tip「别敲啦」+ social −0.1（§3.4）。
- 双击（片上 double-tap）：**彩蛋**——表情轮播下一个 clip + tip「换个脸～」。给用户一个「发现隐藏功能」的时刻。
- 运动中的碰撞（Tap 且正在平移）：立即停 0.5s → `o` → 反向 nudge → 恢复原行为。

### S8 被抬起 / 放下（安全 + 表演双重）¹
- 抬起判定：WoM 中断 + 加速度模长偏离 1g >0.15g 持续 300ms（接轮后再加「duty>0 但编码器无地面反馈」旁证）。
- 时间轴：**R0 反射轮全停（≤50ms，先于一切表演）** → `o`(NOW) + tip「哇——放我下来」→ 悬空期间进 LIFTED 态（新增态，见 §4 末注），运动恒零，表情保持 `o`。
- 放下：静置（加速度方差小）1.5s → `PLACED` → 眨眼感（o→waiting FADE）→ 10s 惊魂期动作减半 → 回 IDLE/ENGAGE。

### S9 被拨轮 / 被推动 ¹′²
- 触发：`WHEEL_MOVED`（未驱动却有编码器计数，>1/4 圈）。
- 反应：`o`(NOW) + 朝被拨的轮子方向微转（三轮计数能分出哪个轮）+ tip「咦？」。连续拨弄 3 次 → 判定「在玩我」→ tip「好玩吗 :P」+ social +0.05。**把干扰变成互动。**

### S10 暗光瞌睡 / 亮光醒 ¹
- lux <10 持续 30s（滞回：>30 才算亮）→ **DOZE 态**（新增）：`sleep`(FADE)，微动作停，检测帧率可降半省功耗，energy 加速恢复。
- 退出：`BRIGHT` / 任何刺激（TAP/TOUCH/WAKE/FACE_PRESENT）→ S2 的「揉眼」唤醒序列。夜里被强光突然照 → 先 `o`「被闪到」再醒。

### S11 无聊自主行为（IDLE 久了）²
- 触发：IDLE >90s，泊松采样（λ 随 energy：精力高约 45s 一次，低则数分钟）。
- 行为池（随机+不重复上一个）：慢扫张望（wz ±30°）｜原地小转圈 360°（低速）｜短打盹 10s（sleep→自醒）｜tip 自言自语（「今天真安静」）。
- **硬约束：自主行为只做零位移动作（旋转/摆动），绝不平移**——无悬崖传感器，无人监督时不移动（§7）。

### S12 语音会话姿态 ⁰′²
- LISTEN：身体朝人转正锁定（R2 只留 wz）+ `waiting` + tip「(听)」；SPEAK：随音频播放做 wz ±3° 轻微节奏摆²；THINK：静止 + `think`。会话全程忽略 S3 微动作。现有状态机不动，只加姿态输出。

### S13 上位机交互反馈（详表见 §6）⁰
远程命令不能只有静默执行——设备侧要有可见回应，否则演示时「上位机在控制」这件事本身不可见。

### S14 堵转 / 卡住 ¹′²
- 判定：单轮电流 >350mA 持续 200ms（实测堵转 400mA/个）且 |rpm|<5 且 duty>30% → **R0：STBY 拉低** → FAULT + `sad` + tip「卡住了，帮帮我」。
- 恢复：3s 后自动试探解除一次（duty 25% 反向 0.3s）；连续 3 次失败 → 锁定等 `clear_fault`（上位机或触摸长按 5s¹）。

### S15 低电量（载板阶段）³
IP5306/电量寄存器 <20% → 基调转 `sad` 倾向 + tip「有点饿了」；<10% → 运动禁用只剩表情。V1 无 PCB 版无电量计，仅列设计。

### S16 专注勿扰（PC：work/meeting/dnd）⁰*
- 触发：许可等级进入「勿扰/静默」（§3.5）。
- 行为：不主动接近、不邀玩、微动作降频（meeting 全停）；人凑近看它仍正常回应（是懂事，不是死机）；退出专注后第一次对视 → tip「忙完啦？」（近因记忆，§3.4）。
- **这是「智能感」性价比最高的场景**：机器人「知道你在忙」远比会卖萌更像有脑子。

### S17 挂机邀玩（PC idle + 人在视野）⁰*′²
- 触发：`idle_s > 300`（可调）且 present 且非勿扰，泊松采样防每次准点骚扰。
- 时间轴：歪头（tilt_glance）→ 前进 nudge 3cm² → tip 变体池（「休息一下？」「陪我玩会儿」）→ 30s 无回应（无对视/无触摸）→ 安静退回原位，1 小时内不再邀（记忆）。social 高时更频繁，低时只歪头不上前。

### S18 锁屏离席 / 解锁迎接（PC locked ↔ active）⁰*
- `locked`：预期离席——随后 `FACE_LOST` **跳过 S6 失落表演**（它「知道」你是去忙了），直接安心加速进 DOZE。
- `locked→active`（解锁）：预期回归——提前退出 DOZE、朝惯常方向张望²；随后 `FACE_PRESENT` → S2 迎接升温版（tip「回来啦」）。**预期→兑现的闭环是「它记得我」的核心错觉。**

### S19 陪看/节奏（PC media=true）⁰*′²
- 人在 + media：进「陪伴」等级——对话类 tip 静默，偶发 wiggle 轻摆（像跟着晃）²，凝视阈值放宽（看屏幕的人侧脸多，别误触 GAZED 退避）。

> S16–S19 均为策略调制，不新增状态机顶层态；⁰* = 设备侧 I0 可做，但依赖上位机 F11 上报（外包 11，可并行）。

> **状态机改动**：新增 `LIFTED`、`DOZE` 两个顶层态（协议 `soul` 字段是字符串、取值只增，符合 09 前向兼容铁律；上位机需求 11 附录 C 相应补两行，未知态按原名显示）。其余场景全部是现有 9 态内的行为/表情/tip 扩展，不动枚举。

## 5. 运动语言（原语库）

全向轮不该只会「前进后退」。原语 = 参数化 `(vx,vy,wz)(t)` 曲线，统一带**缓入缓出斜坡（100ms）**与 **±15% 参数抖动**（P3 原则）：

| 原语 | 曲线 | 用途 | 默认参数 |
|---|---|---|---|
| `turn_face` | wz=-k·cx 比例控制 | 朝人转正（持续） | k=0.8（现有） |
| `nudge(dir,d)` | 单方向梯形速度 | 小步进/退缩 | d=3–8cm，duty≤30% |
| `retreat_shy` | 后退 + 同时转开 | S5 害羞 | 退 6cm 转 15° |
| `wiggle` | wz 正弦 1–2 周期 | 开心/歌唱节奏 | ±5°，1.2s |
| `tilt_glance` | 单侧转 + 停 + 回正 | 歪头（好奇） | ±8°，停 0.5s |
| `scan` | wz 慢速三角波 | 张望/找人 | ±30°，0.3rad/s |
| `spin` | 原地 360° | 自主行为彩蛋 | 低速一圈 |
| `shiver` | wz 高频小幅 | 害怕（P1 素材配套时用） | ±2°，4Hz，0.8s |
| `approach_prop` | vx 随 area 误差比例+减速带 | S4 靠近 | 见 §4-S4 |

安全包络（原语层强制，仲裁器之外再兜一层）：duty ≤`motion.max_duty_pct`（默认 40%）；加速度斜坡 ≥100ms；**任何原语可被 R0–R3 即时打断**；平移类原语必须声明位移预算并用编码器里程结算。

## 10. 智能感验收清单（演示视角，逐条可打勾）

1. 走进视野 1s 内：它「惊讶 → 转向我 → 安顿下来」。
2. 站着不动看它 2 秒：它害羞躲开，且 tip 每次说得不一样；30s 内再盯，它不再上当。
3. 敲它一下：立刻「呀」+ 缩一下；再敲：反应明显升级。
4. 拿起来：轮子**瞬间**停 + 惊慌脸；放下：定 1.5s 神才恢复。
5. 关灯 30s：睡着；开灯：揉眼醒来。
6. 拨它轮子玩：它发现了，还觉得好玩。
7. 谁都不理它 2 分钟：它自己找事做（张望/转圈/打盹），且每次不一样。
8. 上位机发 teleop：它「被遥控中」表情上脸，松手 300ms 内自己停。
9. 卡住它：立刻断电停转 + 求助脸，挪开障碍它自己再试。
10. 以上全程断网成立（除语音对话与 PC 融合）——**杀手锏话术的具象版**。
11. 我在电脑上开会/开勿扰：它真的不来烦，凑过去看它、它也只安静回望——**「它知道我在忙」**。
12. 电脑挂机 5 分钟：它歪着头凑过来邀玩；不理它就安静退回去，且一小时内不再来第二次。
13. 锁屏起身：它不演失落、直接安心打盹；解锁坐下：它已经在朝我这边张望了。
