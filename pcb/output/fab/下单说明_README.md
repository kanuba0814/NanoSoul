## 板子制造参数（下单页填这些）
- 层数 **2 层**；尺寸 **92 × 92 mm**；板厚 **1.6 mm**；铜厚 1oz；表面处理 HASL 无铅(或沉金)。
- 外形：圆角矩形（Ø108 圆四边切平），**最外围 1mm 白边**（铜距外缘 ≥1mm，常规铣外形余量）。
- **⚠️ 中部 15.5 × 59 mm 矩形通槽（铣槽 routed slot）** —— 在 Edge.Cuts 上，务必让厂家**按内框铣穿**（竖插开发板的底面件/FPC/microSD 从这穿过）。系统没自动识别内槽就备注说明。
- 孔：6 个 NPTH 非金属化安装/定位孔（4×M3=Ø3.2 立柱、2×M2=Ø2.2 定位）。位置见 `enclosure/DIMENSIONS.md`。
- **双层 GND 铺地已填**（F.Cu+B.Cu，GND 焊盘实连，给电机回流低阻），出 Gerber 已含。
- 最小线宽/间距：本设计 ≥0.2mm（USB-C/合并盘区有 0.08mm 例外规则，已在 .kicad_dru），常规工艺即可。

## ⚠️ 贴片前必须确认（不看会装错/缺料）
1. **开发板不在本 BOM 里**。载板只贴自己的件；开发板靠 J3/J4 母座对插。
2. **SMD 件 27 行已全带 LCSC**，JLC SMT 一遍能识别。**唯一留空：`R9 = 0.05Ω 0805` 电流采样 shunt** —— JLC「Current Sense Resistors」类目里挑一个**在库**的 0805 低阻件填进去即可（阻值不卡死：0.02~0.1Ω 都行，固件标定电流；别匹配成普通厚膜 0.05Ω）。这是下单前唯一要自己点一下的料。
3. **THT 连接器自己手焊（推荐）**：`J3`/`J4`（1×20 立式母座，开发板靠它对插、**行距 17.80mm**）、`J5`/`J6`/`J7`（1×6 2.54 排针，电机束线）、`J1`（JST-PH 电池）。
   - 这几件 **SMT 不贴**。母座 J3/J4 尤其建议自备 + 手焊，保证行距精度与可插拔。要省事也可在 JLC 选「**THT 装配**」加项（J1 已带 `C131337`；1×6 排针参考 `C37208`；1×20 单排母座按需在 LCSC 选）。
   - `J2`(USB-C)、`J8`(JST-SH 光照) 都是 **SMD，SMT 能贴**。
4. **极性件旋转必核对**：BOM「类型/备注」标了「极性/旋转核对」的件（所有 IC、二极管 D1-D5、电解 C8、**USB-C J2**）。**上传 CPL 后看 JLC 预览，逐个核对 pin1/阴极/正极/USB-C 朝向** —— KiCad 与 JLC 库朝向常差 90/180°，这是 PCBA 最易错的点。
5. **库存薄的件下单前查**：`L1`(`C2047296` 2.2µH)/`L2`(`C703091` 4.7µH) 6.3×6.3 功率电感库存偏薄，缺货就换同封装高 Irms 同感量件。
